# Appointment Management System

A terminal-based appointment management system built with Python.  
This project allows users to create, view, update, and delete appointments using JSON file storage.

---

## Features

- Add new appointments
- View all appointments
- Update existing appointments
- Delete appointments
- JSON-based data storage
- Simple terminal interface
- Clean project structure
- Input validation support

---

## Technologies Used

- Python
- JSON
- OOP (Object-Oriented Programming)
- File Handling
- Datetime Module
